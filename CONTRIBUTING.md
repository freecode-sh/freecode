# Contributing

Thanks for helping improve Free Code.

## Bugs

Use the bug report form and include the smallest set of steps that reproduces the problem. Please remove API keys, credentials, private source code, and other sensitive information from logs or screenshots.

## Ideas and questions

Use a feature request for a concrete product change. Use Discussions for open-ended questions, feedback, and ideas that still need shaping.

## Pull requests

This repository contains public community documentation and templates, not the Free Code product source. Pull requests may improve the files that are present here, but product-code changes cannot be submitted through this repository.

## Security

Do not open a public issue for a suspected vulnerability. Follow [SECURITY.md](SECURITY.md) to report it privately.
