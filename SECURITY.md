# Security policy

## Supported versions

Security fixes are made for the latest released version of Free Code. Update to the newest version before testing whether an issue is still present.

## Reporting a vulnerability

Please use GitHub's [private vulnerability reporting form](https://github.com/freecode-sh/freecode/security/advisories/new). Do not disclose the vulnerability in a public issue or discussion.

Include:

- the affected Free Code version and operating system;
- clear reproduction steps;
- the impact you believe the issue could have; and
- any suggested mitigation, if you have one.

Remove passwords, API keys, personal data, and unrelated private source code from your report. We will use the private advisory to coordinate follow-up and disclosure.
